# BaoBao V0.4

留学生 AI 学业 + 生活伙伴。基于 V0.3 的 Flask 应用升级首页，保留原有文字、单张截图、图文联合分析、重要程度与英文回复草稿。

## 运行

使用 Python 3.10+，安装 `pip install -r requirements.txt`。

- 正常运行：`python app.py`，打开 http://127.0.0.1:5000 。继续使用原有服务地址、服务端密钥与模型环境配置；模型需支持图片和 JSON 输出。不要把密钥放入前端、日志、文档或提交到版本库。

## 本轮首页

- 按用户提供的最终效果图调整奶油白背景、橙色花朵标识、字体、圆角、淡彩卡片和紧凑输入区。
- 蓝色 BaoBao 保留用户原角色，独立透明 PNG 去除白背景与笔记本第三方标识；未与城市图片合成。
- Sydney 背景直接使用用户提供的 1536×1024 高清原文件，未加黄色滤镜。吉祥物透明 PNG 为 1145×1374，足够当前高 DPI 显示尺寸。
- 四个主入口：学习、生活、聊天、我的事情。工具保留选课建议、周边生活、邮件草稿、题目解释、入境／签证、中英翻译；沿用用户指定的“选课建议第一、周边生活第二”。
- 中文、English、中英双语切换界面，并用于下一次 AI 输出；已有分析正文不会自动翻译。英文草稿始终为英文。
- 支持学校和城市设置，未列出的国家、城市、学校可选 Other；不会阻止提问。
- Shaoli 是指定的首页展示名，不代表已建立账号或读取个人资料。

## 当前能力边界

文字与截图入口真实调用原 `/analyze`；快捷工具在提交时添加问题背景。结果仍显示重要程度、解释、截止时间、行动、风险、不确定项和英文草稿。不会发送邮件。

我的事情、任务、Deadline、提醒和语音尚未实现，明确显示即将开放。页面不保存任务或个人档案，没有假任务数量。聊天支持本机历史记录及最近连续对话上下文。周边生活使用所选城市作为背景，未接入实时定位、商家或地图。签证和选课建议没有实时官方检索，需核对官方信息。

## 结构与扩展

- `app.py`：原 Flask 路由、系统提示词、图片转换与 AI 调用，保留原接口并扩展聊天上下文隔离。
- `templates/index.html`：语义化首页、结果卡片、设置与占位弹窗。
- `static/style.css`：手机优先的布局及桌面首屏适配。
- `static/app.js`：上传、语言、快捷工具、设置、分析结果交互。
- `static/city-config.js`：Country → City → University 前端目录及城市主视觉映射。Sydney、Melbourne、Brisbane 和 Other 可用。以后可加入 UK / London 及独立 Big Ben 资源；Course / Student 预留为后续领域数据，不创建空数据库或假资料。
- `static/images/sydney-hero-original.png`：用户提供的高清 Sydney 资源原件副本。
- `static/images/baobao-blue-cutout.png`：蓝色吉祥物透明衍生素材。
- `static/images/brand-flower.svg`：首页花朵品牌图形。
- 之前的图片资产仍保留，但当前首页不再引用旧小熊或旧城市照片。
- `tests/test_app.py`：不读取环境配置、不发送外部请求的回归测试。

## 检查

`python -B -m unittest discover -s tests -v`

覆盖首页与资源、空输入、三种输出语言、真实 PNG 字节的截图／图文请求、学校背景、英文草稿、三种重要程度、上游错误和非 JSON 兜底。测试用 AST 在内存中隔离环境读取并拦截网络；不改写应用源文件。

不要将真实 API Key 写入 HTML、JavaScript、README、GitHub 或日志。`.env` 继续由 `.gitignore` 忽略。真实 AI 连通性需要用户在正常启动环境下自行验证；模拟测试不能证明服务商和额度有效。

## PDF / Word 文件上传

现有“上传文件”按钮支持 PDF、DOCX（不支持旧版 DOC）。可单独上传，也可结合问题、截图一起提交到原 `/analyze` 真实 AI 接口。只发送实际提取的文字；不识别文件内的图片、图表或复杂排版。扫描 PDF 无可读文字时会明确报错，混合 PDF 会提示未读页码，不会视为全文已读。

- 每份文件最多 8 MB、PDF 最多 100 页、文字最多 60,000 字符。超限拒绝并提示拆分，不静默截断。DOCX 解压内容最多 20 MB；不支持加密文件、宏文档或损坏的文件。
- 解析在独立子进程进行，15 秒超时，带 CPU/内存资源保护；DOCX 不解压到目录，不解析 XML 外部实体。上传原文件不会永久保存；Flask 可能使用请求结束即关闭的临时上传流。
- 文件文字保留在服务进程内存中，最多 32 份上下文；有效期为 8 小时，定时及访问时清除过期条目。重启、到期或容量淘汰后会明确要求重新上传。当前实现适用于本地单进程服务。
- 浏览器在 IndexedDB 中按对话保存随机上下文标识、文件名及提取提示，不保存原文件或提取全文；有效期内刷新后仍可追问。点击“移除文件”会停止附带文件全文，但不会清除既有对话文字。
- 缺少的截止时间或要求须明确回答“文件中未找到”，数字、单位和时区按原文保留；AI 建议仍需核对原文件。

新增实现：`document_uploads.py`（安全提取及临时上下文）、`static/documents.js`（文件选择与上下文）。`tests/test_documents.py` 使用实际生成的 PDF/DOCX 测试解析、限制、异常和追问传递。回归测试拦截 AI 网络调用，只验证接口契约；真实 AI 测试必须另行通过正常运行服务执行，不能用回归响应代替。

启动前安装更新后的依赖：`python -m pip install -r requirements.txt`。端口 5000 被占用时，可运行 `python -B -m flask --app app run --host 127.0.0.1 --port 5055`。文件功能请使用这个正常服务验证。


## 统一聊天与作业协作

首页输入、上传和学习／生活／聊天入口进入独立聊天视图。消息单独滚动，输入区固定在视图底部；支持加载、错误重试、历史切换和返回首页。首页原有视觉与昵称、学校设置保持不变。

- 作业解释后可继续要求初稿、分步指导或检查；当前完整初稿单独传给 AI，支持指定部分修改、手动编辑保存及复制。实际回答仍来自已有真实 AI 接口，要求不编造数据、文献、文件要求，并提醒学术诚信。
- 聊天文字与初稿仅保存在当前浏览器的 IndexedDB，最多 20 个聊天，每个保留最近 40 条消息。AI 使用最近 6 组完整问答及当前初稿；并非永久记住所有旧消息。
- 附件上下文仅在本地服务内存保留最多 8 小时，文档最多 32 份、截图最多 8 份。原附件不写入 localStorage 或 IndexedDB。浏览器只存随机引用和文件名；重启、过期或容量淘汰后需重新上传，历史文字及初稿仍可恢复。
- HttpOnly 随机访客 cookie 与对话 ID 共同绑定附件；不同浏览器身份及不同聊天不能复用彼此的附件引用。没有登录系统，同一个浏览器配置中的使用者共享本机记录；共用设备应清除记录或使用独立浏览器配置。
- 删除聊天同时撤销对应上下文；清除全部记录同时重置访客身份。清除浏览器站点数据也会丢失历史。此阶段不提供云同步或跨设备恢复。

新增文件：`chat_support.py`、`templates/chat.html`、`static/chat.js`、`static/chat-store.js`、`static/chat.css`、`tests/test_chat.py`、`tests/test_chat_store.cjs`。已有 `app.py`、`document_uploads.py`、`static/app.js`、`static/documents.js` 和首页模板仅做所需集成。

检查：`python -B -m unittest discover -s tests -v`（32 项）；`node tests/test_chat_store.cjs`。自动回归拦截 AI 网络，覆盖接口契约、上传解析、语言、日期准确性提示、上下文隔离、到期与删除、长初稿及历史边界。另已用实际 DOCX 和真实 AI 完成上传解释 → 生成初稿 → 简化第三部分的浏览器流程，计算结果 70 / 80 / 相差 10 正确，前两部分保持不变。已检查刷新恢复、历史切换、手动编辑、删除、损坏文件重试及 390px 布局；真实手机系统键盘仍需实机验收。
