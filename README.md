
# 留学生AI助手 V0.3

V0.3 的核心变化：支持截图上传 + 多模态 AI 分析。

## 当前体验
学生可以：
- 选择学校
- 上传截图
- 补充一句问题
- AI自动分析截图
- 输出：
  - 重要程度
  - 这是什么
  - 截止时间
  - 下一步行动
  - 不处理的风险
  - AI不确定的地方
  - 如果需要回复，给英文回复草稿

## 运行方式

1. 安装 Python 3.10+
2. 打开本项目文件夹
3. 执行：

   pip install -r requirements.txt

4. 复制 `.env.example` 并改名 `.env`
5. 填入：

   AI_BASE_URL
   AI_API_KEY
   AI_MODEL

注意：AI_MODEL 必须支持图片理解 / 多模态输入。

6. 执行：

   python app.py

7. 浏览器打开：

   http://127.0.0.1:5000

## 安全提醒
- 真实 API Key 不要发给别人
- 不要写在前端 HTML
- 当前版本没有登录、权限、数据库和正式隐私保护
- 不要上传护照、银行卡、签证号等敏感信息做公开测试
- 如果以后给真实用户用，要正式做隐私政策、数据存储和权限控制
